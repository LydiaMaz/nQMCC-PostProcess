# nQMCC-PostProcess

Post-processing tools for nQMCC output files.
Part of the [nQMCC-Py](https://github.com/LydiaMaz/nQMCC-Py) ecosystem.

## Maintainer
Lydia Mazeeva (WASHU)

## Overview

This repository provides scripts for scraping, analyzing, and visualizing results
produced by nQMCC calculations.

Planned functionality includes:
- Energy and variance table generation
